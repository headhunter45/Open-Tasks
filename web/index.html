Engineered for Developer Velocity

Designed from first principles around Git workflows, filesystem integrity, and portable distribution.

📁

Repository-Native Storage

Every task, bug, epic, and meeting is an individual Markdown file in .ot/tasks/. All changes branch, merge, and diff directly with your source code.

📦

Standalone ZipApp Binary

Packaged as a single self-contained .zipapp archive. Zero pip dependencies, zero virtual environment overhead, running cleanly on Python 3.10+.

🔑

UUIDs & Git-Style Short IDs

Globally unique UUIDs prevent distributed merge conflicts, while ergonomic Git-style 6-character prefixes (e.g. ab44e2) keep CLI usage lightning fast.

🛡️

Transactional Upgrades

ot upgrade isolates migrations in temporary workspaces, validates schema constraints, and executes atomic replacement with automatic rollback on error.

🩺

First-Class Validation

ot check and ot check --fix detect broken dependencies, cyclic hierarchies, and missing frontmatter fields with automated repair suggestions.

⚡

Optional Wrapper Scripts

Project wrappers (./otw and ./otw.bat) allow team members to run project-locked versions without global machine installations.

CLI Workflow at a Glance

Inspect common operations from initialization to self-hosted release builds.

# In your repository root, initialize Open Tasks
$ ot init
Initialized Open Tasks project in /Users/dev/my-project/.ot
Created configuration in .ot/config.json
Installed default templates in .ot/templates/
Installed project binary in .ot/bin/ot.zipapp
Created wrapper script: otw

# Verify project version
$ ./otw version
Open Tasks v0.1.0
Project root:       /Users/dev/my-project
Configured version: 0.1.0
Installed version:  0.1.0
# Create a new feature task with template generation
$ ./otw task create --title "User Authentication Flow" --type feature --size medium
Created work item: 4a9f2b (User Authentication Flow)
Location: .ot/tasks/UserAuthenticationFlow/index.md

# Query the active backlog
$ ./otw task list --status planned
ID       Title                        Type         Status
-------- ---------------------------- ------------ ------------
4a9f2b   User Authentication Flow     Feature      Planned

# Transition task lifecycle & add comment
$ ./otw task status "User Authentication Flow" in_progress
$ ./otw task comment "User Authentication Flow" "Integrating OAuth2 token validation."
# Perform zero-warning diagnostic check across all tasks & frontmatter
$ ./otw check
Project check passed: No errors or warnings detected.

# Machine-readable JSON output for CI/CD gates
$ ./otw check --json
[]
# Perform non-destructive transactional upgrade with rollback protection
$ ot upgrade --version 0.2.0
Validating target version 0.2.0...
Staging upgrade in isolated temporary workspace...
Applying schema validation checks...
Successfully upgraded project from 0.1.0 to 0.2.0.
